# Original dataset

Download: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Extract `creditcard.csv` into `data/raw/`. The original file used here has 284,807 rows and 31 columns, including 492 frauds.

SHA-256: `76274b691b16a6c49d3f159c883398e03ccd6d1ee12d9d8ee38f4b4b98551a89`.

An equivalent CSV reserialization may have a different checksum. The loader checks the original schema, finite numeric values, nonnegative Time and Amount, and binary labels. The checksum records provenance, not a claim that different serialization is invalid. Consult the dataset page for current terms before redistribution. The ZIP does not redistribute the data.
