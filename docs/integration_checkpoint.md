# Integration checkpoint and final integration

The initial checkpoint (commit 0d0fb97) added the runner and verification tools while Role 4/5 modules were still pending. They are now merged. The final integration executes the official repository's default full pipeline on the original dataset; it does not copy another repository's successful-run metadata.

## Reproduce

```bash
python run_all.py --check-only
python run_all.py
python -m unittest discover -s tests -v
python scripts/verify_outputs.py
python scripts/execute_notebooks.py
python scripts/verify_submission.py
```

The raw original CSV must be in data/raw/ or supplied with --data to both runner and numerical verifier. Notebook execution reads the documented data/raw path. Fitted model files remain local and excluded from Git.

A quick run with --skip-robustness is labeled quick_run_complete and does not certify full Phase 1 reproduction. Preflight is read-only. Failed in-progress runs must not retain a current success marker.

## Verified interfaces

Frozen split membership and dataset/configuration hashes, legitimate-only preprocessing, train-only GMM selection, row-aligned anomaly scores, model-independent evaluation with exact threshold reload, post-freeze error analysis and validation-only robustness are integrated. The notebook driver executes the seven available notebooks with the chosen Python interpreter.

results/experiment_plan.json and results/run_metadata.json are generated by the official run. results/source_manifest.json records the accompanying source/config hashes. The numerical verifier recomputes score/metric contracts; the submission verifier checks the report paths, archive freshness, notebook outputs and role statuses.

## Evidence and limits

Twenty unit/protocol/integration tests pass. The official full run includes 33 primary GMM fits, four primary models and 26 robustness fits. All seven notebooks execute successfully. Document generation and presentation exports use those same numerical outputs.

The test partition was inspected in earlier work, and this remains follow-up evaluation rather than a new independent holdout. Numerical sensitivity, fixed-study choices and historical data limits remain documented. Automated checks do not certify personal authorship, individual viva preparation or faculty acceptance.
