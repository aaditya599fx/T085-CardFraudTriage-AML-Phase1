# Fitted models and preprocessing

Run `python run_all.py` from the repository root after placing the original CSV in `data/raw/`.

The pipeline saves:

- `gmm.joblib`: selected train-only BIC model.
- `scaler.joblib`: legitimate-training StandardScaler.
- `preprocessing.joblib`: full raw-frame transformation pipeline, including feature engineering.
- `isolation_forest.joblib`, `pca.joblib`, `approx_ocsvm.joblib`: comparator models.
- `preprocessing_5d.joblib`, `preprocessing_10d.joblib`, `preprocessing_20d.joblib`, `preprocessing_29d.joblib`: training-fitted pipelines for the sensitivity studies.

Binary model files are regenerated locally and excluded from Git. The saved split membership, model configurations, scores and numerical results are versioned. Use the recorded package versions when loading fitted models. Load only files generated by a trusted local run because joblib deserialization executes Python code.
